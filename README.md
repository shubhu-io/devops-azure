# 🔷 devops-azure — Microsoft Azure Execution Repository

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Learning Hub](https://img.shields.io/badge/DevOps-Learning%20Hub-blue.svg)](https://github.com/shubhu-io/devops-learning)

Dedicated Microsoft Azure Cloud execution laboratory covering Azure CLI (`az`), AKS Kubernetes cluster management, Azure Blob Storage containers, Virtual Networks (VNet), and Azure SDK automation.

---

## ⚡ Quick Start

```bash
git clone https://github.com/shubhu-io/devops-azure.git
cd devops-azure
chmod +x setup.sh
./setup.sh
```

Execute Azure Cloud automation scripts:
```bash
./scripts/azure-vnet.sh
./scripts/blob-storage.sh
```

---

## 📂 Repository Structure
- `scripts/az-setup.sh`: Automated Azure CLI installer
- `scripts/aks-deploy.sh`: Azure Kubernetes Service (AKS) manager
- `scripts/azure-vnet.sh`: Resource Group & VNet creator
- `scripts/blob-storage.sh`: Azure Storage Account & Blob container script
